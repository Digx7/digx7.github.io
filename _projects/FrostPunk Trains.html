This was an asset pack I made and sold using art assets from my game FrostLoop

Below is the marketing copy found on the games page



The world has frozen over, society has gone.  All that's left is on this train as it struggles against the storm.  Will it become the cocoon for humanity, or the last dying ember as we finally get what we deserve.  

====================================================

This asset pack contains the following hand drawn assets:

  • 10 Unique Train Cars
  • 1 Set of Animated Wheels (3 frames)
  • 16 Unique Background Element
  • 17 Unique Snow Particles
  • 16 Unique Game Icons

=====================================================

These assets where originally made for the game Frost Loop for the GMTK 2025 Game Jam
